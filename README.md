# 桌面宠物（电子宠物悬浮助手）

一只悬浮在你桌面上的电子宠物：每小时提醒你站起来活动、每 20 分钟提醒护眼、
22 点提醒休息，还带待办事项和每周统计。图片可以随时增删替换。

![宠物示例](icon/cat1.ico)

---

## 一、怎么运行

### 方式 A：源码直接跑（最快，需要 Python 3.8+）
```bash
# 安装依赖（只需一次）
pip install -r requirements.txt

# Windows 双击 run.bat；macOS/Linux 执行：
sh run.sh          # 或 python3 main.py
```

### 方式 B：打包成 exe / app（Windows，推荐用 PyCharm）
1. 用 **PyCharm** 打开本项目文件夹；
2. **右键 `build.py` → Run**（或在 PyCharm 底部 Terminal 里输入 `python build.py`）；
3. 脚本自动安装依赖、打包、复制图片，完成后自动打开 `dist\` 文件夹；
4. 产物 `dist\桌面宠物.exe` 双击即可运行；图片目录 `dist\pets\` 可随意增删换形象。

> 为什么不直接双击 `build.bat`？
> ① 如果系统里 `.bat` 文件的默认打开方式被改成别的程序（比如图片查看器），双击会弹"选择打开方式"；
> ② 即使能运行，PyCharm 自带的 Python 不一定会加入系统 PATH，会报"不是内部或外部命令"。
> 用 build.py 完全绕开这两个问题（PyCharm 右键运行时自动使用项目解释器）。

想修复 `.bat` 关联也可以：Windows 设置 → 应用 → 默认应用 → 按文件类型选择默认应用
→ 找到 `.bat` → 选择「Windows 命令处理程序」（没有的话点「在电脑上选择应用」，
浏览到 `C:\Windows\System32\cmd.exe` 并勾选"始终"）。

macOS / Linux 用 `sh build.sh`（macOS 上产物是 app 同等的可执行文件）。

## 二、功能与操作

| 操作 | 效果 |
| --- | --- |
| 按住鼠标左键拖动 | 移动宠物位置（位置自动记忆） |
| 双击宠物 | 随机切换一张形象（每天首次启动也会自动随机换一张） |
| 鼠标滚轮 | 放大 / 缩小宠物（自动记忆；放大不会超出屏幕） |
| 点击宠物头顶的状态标签 | 弹出菜单，手动切换 专注中 / 放松5分钟 / 放松10分钟 / 休息中 |
| 右键宠物 | 菜单：新建待办、本周统计、切换形象、最小化到托盘、退出 |
| 右键 → 最小化到托盘 | 隐藏到系统托盘；托盘图标用 cat1 生成（猫占满图标） |
| 双击托盘图标 / 托盘菜单“显示宠物” | 重新显示宠物 |

> 提示：宠物图片会自动裁掉透明边、按底部中心锚定，切换形象时猫咪位置基本不动；
> 首次启动默认大小约为 180px（旧版本升级会自动把偏大的尺寸重置为新默认）。
> 托盘图标单独用 cat1 生成，不受宠物缩放影响。

### 提醒规则（弹窗显示在宠物头顶，可按住拖动，点击按钮或 30 秒后自动关闭）
- **站立提醒**：每天 09:00–21:00，累计**专注**满 1 小时提醒一次；
  点击「放松5分钟 / 放松10分钟」进入放松状态，**放松的 5/10 分钟不计入**
  下一个 1 小时；
- **护眼提醒**：09:00–22:00 每 20 分钟提醒一次“远眺 20 米外 6 秒”；
- **休息提醒**：22:00 之后每晚提醒一次早点休息，确认后状态变为「休息中」，
  次日 9 点自动回到「专注中」；
- **待办三段式提醒**：创建待办时设置提醒时间和截止时间 →
  ① 提醒时间到弹一次；② 若未完成，截止前 30 分钟再弹一次；
  ③ 仍未完成则截止时再弹一次（弹窗可一键「标记完成」）；
- 弹窗：点按钮立即关闭；**不点的话 30 秒后自动关闭**。
  如果多个提醒撞在一起，会排队依次弹出。

### 状态
- 默认「专注中」；放松时「放松中（剩余 mm:ss）」；22 点后确认休息为「休息中」。
- 当前状态显示在**宠物头顶的标签**上（幼圆字体、白色文字、蓝色描边，点击可手动切换），
  同时也显示在托盘悬浮提示和右键菜单里。

### 待办与统计
- 右键 →「新建待办…」：输入内容 + 选择**提醒时间 / 截止时间**，添加、勾选完成、删除；
- 右键 →「本周统计…」：本周（周一开始）专注时长、站立/护眼/放松/休息次数、
  待办新建/完成数，以及每天情况的柱状图。

## 三、怎么换宠物图片

把图片放进 `pets/` 文件夹即可（支持 png / jpg / jpeg / bmp / webp）。
- 删除图片：宠物就再也不会切到它；
- 新增图片：双击宠物或右键“切换形象”即可看到；
- 建议用**透明背景（已抠图）的 PNG**，效果最好；
- 图片建议单张 5MB 以内：你目前这 5 张约 15–18MB，启动时加载会稍慢。
  可以用画图/PS 压缩到 1–2MB 以内，画面几乎无差别。

## 四、数据都存哪了

打包后全部在 exe 同目录的 `data/` 下（源码运行则在项目目录）：
- `config.json`：位置、缩放、当前形象、提醒进度（删除即恢复默认）
- `daily_stats.json`：每天的各项统计（周统计的来源）
- `todos.json`：待办事项

想重置就把 `data/` 删掉，程序会重新生成。

## 五、想调整提醒时间/间隔

编辑 `scheduler.py` 顶部的常量（改完重新打包或用源码运行）：

```python
ACTIVE_START_H = 9      # 站立提醒开始
ACTIVE_END_H = 21       # 站立提醒结束
EYE_END_H = 22          # 护眼提醒结束
REST_H = 22             # 休息提醒开始
STAND_INTERVAL_SEC = 3600   # 站立间隔（秒）
EYE_INTERVAL_SEC = 1200     # 护眼间隔（秒）
```

弹窗自动关闭时长在 `cloud_popup.py` 的 `AUTO_CLOSE_MS = 30000`（毫秒）。

## 六、常见问题

- **托盘图标不显示**：部分精简版 Windows/无托盘区域环境需要先运行一次
  其它带托盘的程序；Linux 桌面需要安装 AppIndicator 扩展。
- **宠物挡住了桌面图标**：按住左键拖到不碍事的位置即可，位置会记住。
- **多屏**：位置按主屏保存，副屏位置超出范围时启动会自动拉回主屏。
- **打包报错**：确认 Python 是 64 位、`pip install -r requirements.txt` 成功，
  再跑 `build.py`（PyCharm 右键运行）。
- **双击 build.bat 弹"选择打开方式"**：`.bat` 关联被改坏了，见上文"方式 B"
  的修复说明；直接用 PyCharm 跑 `build.py` 即可绕开。

## 七、项目结构

```
desktop-pet/
├── main.py            # 入口
├── scheduler.py       # 提醒引擎（站立/护眼/休息 + 状态机）
├── storage.py         # 配置/统计/待办存取
├── pet_window.py      # 悬浮宠物窗口（拖动/缩放/双击/右键/弹窗）
├── cloud_popup.py     # 云朵弹窗（30 秒自动关）
├── dialogs.py         # 待办对话框 + 周统计对话框
├── tray.py            # 系统托盘（cat1 图标）
├── pets/              # 宠物图片（可增删）
├── icon/              # 打包用的 cat1.ico
├── tests/             # 单元测试 + 冒烟测试 + 渲染验证
├── build.py            # 一键打包（推荐：PyCharm 右键运行）
├── build.bat / build.sh / run.bat / run.sh
└── requirements.txt
```
